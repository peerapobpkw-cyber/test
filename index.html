รายวิชา GE931

Prompt อย่างไร
ให้ได้ผลลัพธ์ที่ดี

บันทึกการทดลอง Prompt กับเครื่องมือ AI หลากหลายประเภท — ตั้งแต่ภาพ กราฟคณิตศาสตร์ แผนภาพ เอกสาร ไปจนถึงเว็บไซต์ที่กำลังแสดงอยู่นี้ โดย Peeraphop Sirithongjak

ดูผลงานทั้งหมด สไลด์ประกอบ

ผลงาน

แต่ละหัวข้อคือการทดลอง Prompt หนึ่งรอบ — จากผลลัพธ์แรกสู่ผลลัพธ์ที่ปรับแล้ว พร้อมสิ่งที่ได้เรียนรู้

เครื่องมือที่ใช้

เครื่องมือ AI และซอฟต์แวร์ที่ปรากฏในผลงานด้านบน

กระบวนการ

สูตรการทำงานที่ใช้ซ้ำในแทบทุกหัวข้อ

Zero Shot

สั่ง Prompt แบบสั้น ไม่มีตัวอย่างหรือบริบทเพิ่มเติม เพื่อดูว่า AI เข้าใจโจทย์ไปทางไหนก่อน

→
Result

ดูผลลัพธ์แรกที่ได้ แล้ววิเคราะห์ว่าจุดไหนตรงและไม่ตรงกับสิ่งที่ต้องการ

→
Few Shot

เพิ่มตัวอย่าง รายละเอียด หรือข้อจำกัดเข้าไปใน Prompt เพื่อลดความคลุมเครือ

→
Refine

ปรับแก้ซ้ำจนได้ผลลัพธ์ที่ตรงตามวัตถุประสงค์ — คือผลลัพธ์ใหม่ที่แสดงในแต่ละการ์ด

สรุปการเรียนรู้

  1. ความละเอียดของ Prompt ส่งผลโดยตรงต่อคุณภาพและความแม่นยำของผลลัพธ์
  2. การให้ AI ซักถามกลับก่อนลงมือทำ ช่วยลดความคลุมเครือได้มากกว่าการเดาเจตนา
  3. เครื่องมือแต่ละชนิดต้องการวิธี Prompt ต่างกัน — สิ่งที่ได้ผลกับภาพ ไม่จำเป็นต้องได้ผลกับโค้ดหรือสมการ
  4. การทำซ้ำและปรับแก้ (Refine) คือขั้นตอนที่ทำให้ผลลัพธ์ดีขึ้นจริง ไม่ใช่การ Prompt ครั้งเดียวแล้วจบ

“Prompt ที่ดี ไม่ใช่ Prompt ที่ยาวที่สุด แต่คือ Prompt ที่คลุมเครือน้อยที่สุด”

การเรียนรู้เรื่อง Prompt ในรายวิชานี้ ทำให้เห็นว่า AI ไม่ได้ให้คำตอบที่ดีที่สุดจากคำสั่งแรกเสมอไป แต่ผลลัพธ์ที่ดีเกิดจากการสื่อสารที่ชัดเจนขึ้นทีละรอบ เหมือนการทำงานร่วมกับผู้ช่วยที่ต้องอธิบายให้เข้าใจตรงกันก่อน ไม่ใช่การออกคำสั่งเพียงครั้งเดียว
